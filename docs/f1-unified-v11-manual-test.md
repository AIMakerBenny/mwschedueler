# MWS F1 통합 v1.1 수동 시험

Production은 변경하지 않았다. 시작 개발 HEAD는 80323001600e2fa0d62002fe19d7d7d7803496c7이며 기존 11개 커밋 위에 이어서 수정했다.

## 실행

Node.js 24에서 저장소를 내려받고 작업 브랜치를 선택한다.

```sh
git switch f1-unified-redesign-v11-20261012
node scripts/serve-f1-unified-v11-preview.mjs
```

http://127.0.0.1:8766 을 열고 Public 선택 → Public 입장 → F1 레이싱으로 이동한다. 시험용 연락처 12명이 제공된다. 참가자·트랙·랩수를 선택하고 기존 그리드 연출이 끝나면 경기 시작을 누른다. 시험 중 로컬 Public 세션에서 연락처도 수정할 수 있다. 클라우드 저장·Admin API는 연결하지 않는다. 실제 사용자 데이터나 Production에 쓰지 않는다. Ctrl+C로 서버를 종료한다.

## 실제 수정

- 같은 스텝의 통합 엔진과 공개된 구 엔진 적분기 중복 실행을 차단했다.
- 랩 차이가 있는 차량도 실제 가까운 트랙 위치로 교통·공력·접촉을 계산한다. 공식 순위는 계속 누적 주행거리와 결승선 통과시간을 사용한다.
- 직선화한 스텝의 두 축 접촉 시간 구간을 교차해 검사한다. 기존 유클리드 최근접 시점 하나만 보는 방법의 누락을 수정했다.
- 접촉으로 거부한 스텝은 차량 AI 타이머·개별 난수·피트 타이머까지 이전 상태로 복원한다. 실패 진단만 남고 시뮬레이션 시계는 되돌아간다.
- 다차량 제동 명령을 중앙 제약기 안에서 반복 전파하며, 잠김 실수 중 줄어든 실제 제동 한계도 반영한다.
- 정지 차량에 너무 늦게 제동하던 비례 제어를 다음 상태의 정지거리 제약으로 교체했다. 속도 변경은 현재 가능한 제동량을 넘지 않으며, 불가능한 접근은 위치를 고치지 않고 안전 정지한다.
- 피트 정차 명령을 접촉 검사 이전에 확정하고 피트 차량도 같은 렌더 경로를 점유하는 동안 교통 검사에 포함한다.
- 실제 마찰 제동 일로 ERS 회생을 기록한다. 실행하지 않은 필살기 요청 출력을 실제 출력으로 표시하지 않는다.
- 필살기의 초·밀리초 비교 오류와 피트 내부 출력 활성화를 수정했다. 연계자는 같은 300kW를 사용하되 시작을 0.4초씩 분산한다. 연출 중 물리·시계는 정지한다.
- 같은 스텝에서 결승선을 통과한 차량은 마지막 위치의 초과량이 아니라 보간한 실제 통과시각으로 순위를 정한다.

회귀 시험: 두 축 연속 접촉, 한 바퀴 차이 접촉, 실패 스텝 전체 차량 필드 복원, 정지·재개, 실행 에너지, 필살기 시작·페이드·피트 분리, 정지 장애물 20초 접근, 실제 연출 어댑터의 3명 연계, 결승선 통과시간 정렬 통과.

실제 Chromium 기본 UI: 7개 트랙 목록, 12대 실제 시작, 약 30초 주행, FHD·QHD의 3개 패널 무겹침, 프로필 마커, 정지·재개의 물리·화면 상태 유지, 구 적분기 호출 차단, 실제 피트 서비스·새 타이어·온도·피트 HUD, 포디엄 3자리, 새 경기 참가자 유지 통과. 피트 서비스는 명시적인 PIT_BOX 시험 초기조건을 사용했다. 완전한 진입·출구 여정의 검증이라고 해석하지 않는다. 포디엄은 기존 강제 종료 시험 API로 확인했다.

```sh
npm install --no-save playwright
MWS_CHROME_PATH=/path/to/chrome node scripts/qa-f1-unified-v11-browser.mjs
```

브라우저 시험은 로컬 Public fixture와 실제 Worker의 HTML·로딩 변환을 사용한다. Production 인증·저장 API 시험은 아니다. Windows에서는 환경변수 설정 방법을 해당 셸에 맞춘다. 스크린샷 저장은 선택 환경변수 MWS_QA_SCREENSHOT으로만 켠다.

## 확인 범위와 남은 제약

시험한 majoku-ring-v1의 현재 줌 및 최대 줌에서 물리 안전 정지와 링 겹침은 관측 0건이다. 다른 경기·시드·모든 줌의 0건을 증명하지 않는다.

기존 14m 트랙 폭, SVG 표시 폭 42.9, 1x 링 외곽 지름을 환산하면 약 12.10m이다. 차량 중심의 사용 가능 횡범위는 -4.5~4.5m로 최대 차이는 9m다. 같은 종위치의 병렬 차량은 이 줌에서 표시 링을 분리할 공간이 부족하다. 구슬 축소·가짜 횡분산·강제 종간격으로 숨기지 않았으며 기하 경고를 유지한다.

현재 접촉 판정은 트랙의 s/y 좌표에서 선형 이동 구간을 검사한다. 세계 좌표의 회전 footprint, 경로 길이 J 환산, 후보 경로별 반복 전후 속도 계획, timing-gate 기반 공력 자격은 기존 초안에서 아직 완성되지 않았다. 해당 부분의 전체 설계 준수 결과는 Not available. 이번 수정은 이를 구현했다고 주장하지 않는다.

모든 7개 트랙의 완주·다중 시드 경기 밸런스·최저 줌 병렬 링·완전한 피트 합류의 전체 검증 결과는 Not available. 사용자 수동 경기 시험과 후속 엔진 작업 대상이다. 기존 UI·트랙 데이터·Scheduler 소스는 교체하지 않았다.
