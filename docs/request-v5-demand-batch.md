# Demand-only media batch V5 candidate
Production feature disabled unless MWS_MEDIA_BATCH_V5=1. Existing R2/D1 and persistent Cache Storage unchanged. Explicit immutable contact URL only; no listing, no remote fetch, no new storage. Deferred visible contacts use one POST per queued group of at most 256; other paths remain unchanged. One response streams each exact R2 object, no archive and no re-encoding. Limits: 32 MiB per image, 128 MiB transfer per group, 96 KiB request. Cache entries individually persisted; missing/failed rows fall back to original route. These bounds and 20 ms coalescing window are candidate settings, not Cloudflare limits. No claim of one request across different visibility waves, or all image classes, or production CPU compliance. Local tests only; deployment requires approval.
