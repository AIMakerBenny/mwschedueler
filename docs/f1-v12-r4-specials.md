# MWS F1 R4 — 2026-10-17

개발 브랜치만 업데이트. Production 미수정.

필살기 자체는 레이스를 멈추지 않는다. 2050ms의 실제 화면 시간차로 체인 부스터가 하나씩 활성화되며, 수동 일시정지는 발동과 애니메이션을 모두 보류한다. 기존 통합 물리 엔진의 300kW/10초(시뮬레이션 시간) 부스터는 유지.

기존 지도 전체를 어둡게 덮던 중앙 배너를 투명한 상단 중앙 소형 배너로 교체. 썸네일 외부의 SVG 불꽃/발광 링은 실제 부스터가 유효한 차량에서만 표시하며, 원본 사진과 물리/추월 판정을 변경하지 않는다.
