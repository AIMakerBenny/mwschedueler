# MWS F1 v1.2 — R2 다차량 추월 통로 계획

**개발 브랜치만 변경, Production 미반영.**

기존 추월 AI는 좌·중·우 3개 대표 후보만 검사했으나, R2는 0.75m 간격 + 주변 차량의 물리적 안전통로 경계 + 현재 위치 + 이상적인 레이싱 라인을 함께 평가한다.

\`unifiedAttackCorridorV12\`는 0.65, 1.5, 2.8, 4초 시점에서 상대 속도와 예상 횡방향 움직임에 따른 공간을 확인한다. 접근 시간 대비 차선 변경 가능거리(2.5m/s)를 초과하는 후보는 버린다. 가까운 제3차량이 한쪽 통로를 막으면 다른 통로를 선택할 수 있다.

**절대 보존:** \`unifiedMergeTargetV11\`의 실제 가까운 차선 병합 봉쇄(피트 합류 차량도 포함), \`unifiedLateralV11\`, 20ms 물리 스텝, 다차량 충돌 예측 및 실제 swept-world 판정, 추월 crossing 이후 500ms 확정 규칙, R0 진단/ R1 주행 성향, 타이어·ERS/피트. 물리 충돌을 뚫거나 차량 위치를 강제로 바꾸지 않는다.

상태 \`PLAN_ATTACK\`, \`FOLLOW\`, \`EXIT_DUEL\`, \`SIDE_BY_SIDE\`, \`PIT\`은 유지하며, 트랙 장애물 앞에서 실제 물리적 공간이 없으면 공격하지 않는다. 후보 수는 R0 진단 샘플의 \`corridorCandidates\`로 관측할 수 있다.

QA: 12대 120초 격리, 역순 차량 배열, 제3자 봉쇄, 피트 구역 차량의 가까운 물리적 병합 금지, 지나치게 좁은 트랙, RNG/물리 상태 변경 방지. 실제 7 SVG 짧은 물리/Chromium 회귀. 장거리·다중 시드에서 순위 변동이 충분한지는 아직 검증되지 않았으며 R5에서 별도 확인.
