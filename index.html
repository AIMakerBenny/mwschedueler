저장 방식 안내

Admin 변경사항은 온라인 공유 데이터에 저장됩니다. Public 변경사항은 현재 세션에만 남고 새로고침하면 사라집니다. Public에서 작업 내용을 유지하려면 전체 백업 JSON을 내보내 주세요. 테마, 배경, 글자 크기, 해상도 같은 개인 화면 설정은 각 브라우저에 자동 저장됩니다.
수동 JSON 백업 권장

전체 백업

스케줄, 연락처, 메모, 이미지, 카테고리, 합방 기록 등 현재 작업 데이터를 저장합니다. 프로필 이미지는 백업 파일 안에 직접 포함됩니다. 개인 화면 설정은 브라우저에 별도로 저장되므로 백업에 포함하지 않습니다.

폴더에서 연락처 사진 업데이트

이미지 파일명이 기존 연락처의 표시 이름과 정확히 일치하면 다른 정보는 건드리지 않고 프로필 사진만 교체합니다. 예: 마이곰이.png → 연락처 마이곰이.
선택 전
연락처 이름, 태그, 방송국 URL, 메모, 합방 기록은 변경하지 않습니다. 같은 이름의 연락처가 2개 이상이면 오등록을 방지하기 위해 해당 파일은 건너뜁니다.
폴더 또는 이미지 여러 장을 선택하면 파일명을 연락처 이름과 비교한 뒤 바로 사진을 업데이트합니다.

현재 브라우저에 저장된 메인 데이터의 대략적인 사용량을 표시합니다.
확인 중

데이터 안내

Admin은 변경사항을 Supabase 공유 데이터에 저장합니다. Public은 모든 기능을 사용할 수 있지만 변경사항은 현재 세션에만 적용되며 서버나 다른 이용자에게 기록되지 않습니다. Public 작업을 유지하려면 전체 백업 JSON을 직접 내보내 보관해 주세요.
